Request Data Flow

1
User Interaction
User changes filter in FilterBar.vue (period, warehouse, category, status)
›
2
useFilters()
Singleton composable updates reactive refs. Shared across all views — watcher triggers reload.
›
3
api.js
Converts filter state to URLSearchParams. Skips params equal to 'all'. Fires Axios GET.
›
4
FastAPI Endpoint
Receives optional query params. Calls apply_filters() and filter_by_month() helpers.
›
5
In-Memory Filter
Filters list copy by warehouse (exact), category (lowercase), status, month/quarter substring match.
›
6
Pydantic Validation
Filtered dicts validated against response model. Serialized to JSON array.
›
7
Vue Computed
Raw data stored in ref(). Derived values (totals, charts) live in computed() properties.

Known Gaps & Notes

Missing Backend Endpoints

  • Tasks CRUD — client calls GET/POST/PATCH/DELETE /api/tasks but no endpoint exists
  • Purchase Orders — POST /api/purchase-orders called from BacklogDetailModal, not implemented
  • purchase_orders.json exists but is empty — data won't persist without backend support

Design Constraints

  • No persistence — all data resets on server restart
  • No auth — useAuth always returns isAuthenticated: true
  • CORS open — allow_origins=["*"] is dev-only
  • Inventory — no month/time filter (no time dimension in data)
  • Revenue goal — $800K/month single, $9.6M YTD all months
